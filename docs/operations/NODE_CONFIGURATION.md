# Node Configuration Reference

`vnetwork-node` loads defaults, optional `--config <node.toml>`, and environment variable overrides:

- `NETWORK_ID`, `NETWORK_NAME`, `NETWORK_PROFILE` (`DEVELOPMENT` | `TESTNET` | `PRODUCTION`)
- `NETWORK_PROTOCOL_VERSION` (`vector-network/1.0.0`)
- `NETWORK_NODE_KIND` (`VALIDATOR_NODE` | `FULL_NODE` | `BOOTSTRAP_SEED` | `LIGHT_PARTICIPANT`)
- `NETWORK_ENABLE_P2P`, `NETWORK_ENABLE_PUBLIC_API`, `NETWORK_ENABLE_VALIDATOR`
- `NETWORK_LISTEN_ADDRESSES` / `NETWORK_P2P_LISTEN_ADDRS`, `NETWORK_ADVERTISED_ADDRESSES`, `NETWORK_BOOTSTRAP_PEERS`
- `NETWORK_PUBLIC_API_BIND` / `NETWORK_API_LISTEN_ADDR`, `NETWORK_PUBLIC_API`
- `NETWORK_STORAGE_PATH`, `NETWORK_NODE_IDENTITY` / `NETWORK_IDENTITY_PATH`, `NETWORK_VALIDATOR_KEY_PATH`, `NETWORK_VALIDATOR_ID`
- `NETWORK_GENESIS_FILE`, `NETWORK_ALLOW_BOOTSTRAP_ATLAS`, `NETWORK_TLS_CONFIGURATION`
